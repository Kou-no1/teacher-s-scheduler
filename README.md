# 週案エディタ

単一HTMLのReact参考実装。週案 / 行事カレンダー / 時数・年間指導計画を、ブラウザ内のデータで扱います。

- アプリ: `index.html`
- 現行設計: [docs/architecture-v2.md](docs/architecture-v2.md)
- 旧設計: [weekly_planner_design.md](weekly_planner_design.md)
- GAS: `gas/Code.gs`、`gas/appsscript.json`

## 起動

`index.html` をブラウザで開くか静的ホスティングで配信してください。React・Babel・SheetJS・フォントの初回取得にネット接続が必要です。週案と取り込みExcelをサーバーへ送る処理はありません。Google連携時は行事名・日付だけを明示的に送ります。

## Excel

行事: 日付 / 行事名、または月 / 日 / 行事名の縦型表を指定します。

年間指導計画: 単元 / 配当時数 / 予定月の縦型表を指定します。シート・見出し・最終行・各列を選んでプレビューを確認してください。出版社固有の複雑なレイアウトを自動変換する機能はまだありません。

取り込んだ単元をコマ編集で指定し、授業後に「実施済み」にすると単元進捗へ反映されます。過去日付の計画は自動で実施扱いにしません。

## 保存

`weeklyPlan_v2` に保存します。旧 `weeklyPlan_v1` は原本を残して移行します。破損・未対応版は自動保存を止めて復旧案内を表示します。端末・ブラウザ・配信URLを変える前に設定からJSONを書き出してください。JSONにはメモも含まれるので、公開リポジトリには入れません。

## GASで配信

1. `node scripts/build-gas.mjs` で `gas/Index.html` を生成します。
2. Apps Scriptプロジェクトに `Code.gs`、HTMLファイル `Index`、マニフェスト `appsscript.json` を反映します。
3. 最初は「アクセス: 自分のみ」「実行: アクセスしているユーザー」でテストします。校内共有はWorkspaceのドメイン制限を設定します。
4. 新しいデプロイからWebアプリを選びます。Calendar権限の認可が必要です。
5. GAS版の行事カレンダーに同期先カレンダーIDを指定して同期します。専用カレンダーを推奨します。

本リポジトリから本番GASへのデプロイは実施していません。利用者のプロジェクトID・アカウント・校内の公開範囲で設定する必要があります。`clasp` を利用する場合の `.clasp.json` はGit管理対象外です。

Googleカレンダー同期は作成・更新のみ。再送時は識別子がある行事を更新します。ローカルの削除や日付移動を含む双方向同期は次段階で実装します。週案・児童メモはGoogleへ同期しません。別端末の週案共有には別途本人用Drive保存等が必要です。

GASのiframeやブラウザ設定でlocalStorageが使えない場合は保存エラーを表示します。JSON書出を代替として残しています。

## 開発・検証

`node scripts/verify-core.mjs` で集計・日付・旧データ移行・ICS・GAS同期の回帰検証を実行します。追加でPlaywrightが利用できる環境では `node scripts/verify-browser.mjs` を実行します。公開データ・ライブラリ取得以外に実データの外部送信はしません。各出版社の実ファイルとGoogle本番認可は別途検証が必要です。
