# v3 実装・検証記録

## 実装

- 年度・学年・組・担当教科を持つ学級登録、学級別の週案・タスク・時数。
- 担任/専科切替、全担当学級の時間割、同時刻の重複表示。
- 教科別の年間標準と指導計画は共有し、実施は学級ごとに分離。
- v1/v2からv3への日付年度・学年別移行。保存原本を保持。
- 中止理由・振替元/先の双方向参照、最新状態で空きコマ再検証。
- 休業日・対象学年/限の行事・他担当学級の授業を除いた振替候補。
- 持ち物から準備一覧、週ごとのチェック保存。児童メモを混ぜない。
- 月別/年度別の時数CSV、基準日・範囲・学級を明記。BOM/CRLFと式対策。

## 検証

`node scripts/verify-core.mjs`: 25件。
標準6学年、旧データ、型違い、年度境界、分数時数、単元ID比較、URL制限、Excel日付、重複行事、学級分離、担当教科の標準、振替占有/二重確定/参照解除、週コピー、準備の個人情報分離、CSV期間/式対策、GAS同期モック。

`node scripts/verify-browser.mjs`: Edge headless。
実際のD&D、編集/実施、前週コピー、SheetJSで生成した複数シートExcelの行事・指導計画読込、教材リンク、専科設定、5年1組/6年2組の切替、重複表示、準備チェックの保存/再読込、行事/他学級を避ける振替、CSVダウンロード、破損保存/CDN不通。

1280×800と390×844のスクリーンショットを目視確認。A4横PDFは1ページ、841.92×594.96pt。生成物は `.verification/` に置き、Git対象外。

`node scripts/build-gas.mjs`: 同じ単一HTMLから配信用 `gas/Index.html` を生成。

- 振替候補は未入力枠。学校全体の時間割、夏季休業、他教員の予定は推定しない。
- 実際の採用出版社の複雑なExcel、GAS本番認可/配信は未検証。
- 今回は新しいクラウド送信処理を追加していない。複数端末同期は未実装。
- v3は学級の年度/学年を固定。進級は新学級として登録し、旧実績を保持する。
