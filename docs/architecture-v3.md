# 週案エディタ v3: 専科・準備・振替・時数報告

更新日: 2026-10-03。正本は引き続き単一HTMLの `index.html`。
標準時数・Excel変換・GAS送信境界は `architecture-v2.md` を引き継ぐ。

## 1. 保存契約

```ts
type PlanV3 = {
  version: 3;
  meta: { teacherName: string; schoolYear: number; role: 'homeroom'|'specialist' };
  activeClassId: string;
  classes: Array<{
    id: string; schoolYear: number; grade: 1|2|3|4|5|6;
    className: string; subjectIds: string[];
  }>;
  classPlans: Record<string, { weeks: Record<string, WeekV2> }>;
  subjects: SubjectV2[];
  events: Record<string, Array<EventV2 & { blockedPeriods?: string[]; grade?: number|null }>>;
  curriculum: CurriculumV2[];
  tasks: Array<TaskV2 & { classId: string|null }>;
  preparations: Record<string, Record<string, boolean>>;
};
type LessonV3 = LessonV2 & {
  lessonId: string;
  cancelReason: string;
  rescheduledFrom: LessonRef|null;
  rescheduledTo: LessonRef|null;
};
type LessonRef = { classId: string; date: string; period: string; lessonId: string };
```

`WeekV2.days[].periods[]` のコマを `LessonV3` に拡張する。学年と年度は学級登録時に固定し、翌年度や別学年には新しい学級を追加する。学級名と担当教科は変更可能。授業のない学級も保存する。担任モードの集計は全教科、専科モードは各学級の `subjectIds` のみ。担当外の既存記録は削除しない。

年間指導計画・教材研究リンクは同年度・同学年・同教科で共有。単元の実施数は各学級の週案から独立して計算する。全担当学級の時数を1学級の年間標準で割らない。

## 2. 移行と保存

保存キーは `weeklyPlan_v3`。起動時は v3 → v2 → v1 の順に読み、最初に見つかった原本が破損していたら下位データに勝手に戻さず保存停止。v1/v2キーは削除しない。

旧形式は各日の年度と `week.grade` ごとに学級を生成する。3月/4月をまたぐ週は日単位で分離し、元の教科・単元・メモ・実施状態を保持する。旧タスクは該当年度・設定学年の学級に関連付けるか共通タスクにする。v3は学級ID、週の学年・各日の年度、重複ID、振替参照を検証する。

React stateが正本。500msまとめ保存、終了前保存、別タブ更新検出、JSON全学級バックアップ、保存不能時の警告はv2と同じ。学級切替は表示コンテキストのみを変え、他学級の状態を破棄しない。

## 3. 専科のUI

- ヘッダーの学級選択で年度内の学級を切替。「学級を追加」で学年・組・担当教科を登録。
- 設定で担任/専科を切替。専科は担当教科だけをパレット・時数比較に表示する。
- 専科の「担当時間割」は月〜金×1〜6限に全担当学級を重ねて表示。同時刻に2件以上の非中止授業があれば重複表示。クリックでその学級のコマ編集へ移動。
- 重複は警告であり、学校全体の時間割検証ではない。他の先生の予定や未入力授業は把握できない。
- 担当教科を外しても既存授業は保持する。担当外記録があると通知する。

## 4. 振替

中止コマは消さず `cancelReason` を記録する。「準備・振替」または中止コマから候補を開く。

候補は翌日以降・同学級・同年度・平日・指定範囲内（最大28日）の**未入力コマ**。休業日と行事の明示的な対象限を除外する。専科は他担当学級の同時刻の授業も除外する。学校行事があるだけでは全日休業と推定しない。候補は学校の正式な空き時間を保証せず、利用者が確認して確定する。

確定は最新stateで再検証する。移動元は中止のまま、移動先は新ID・計画状態で単元/小単元/持ち物/メモ/単元IDをコピー。双方向の参照を残す。中止は0時数、移動先は実施済みにするまで0実施時数。

振替済みの移動元は実施への変更・教科変更・削除を禁止。移動先を削除/教科変更したら元の振替参照を解除する。移動先を再度中止して振替する連鎖は可能。週コピーは新しい授業IDにし、状態・理由・振替参照をリセットする。リンクのある週をコピー先として上書きする場合は参照も解除する。

## 5. 今週の準備

「準備・振替」で選択学級または全担当学級の持ち物を集約。中止は除外。改行・読点・カンマ・中点で分割し、同じ文字列をまとめる。数量は推測せず使用コマを表示する。児童メモを混ぜない。

チェック状態は週＋品名＋使用コマ参照の安定キーで保存する。新しい使用コマを追加した場合、以前の準備済みを勝手に引き継がない。入力済み授業だけを対象にする。

## 6. CSV報告

「時数・指導計画」の「時数報告CSV」で年度内の集計開始/終了日・実施基準日、選択学級/全担当学級を指定。月指定で月末報告、年度全期間で年度末報告。

1行=1学級×1教科。年度、学級ID、学年、組、教科、集計期間、基準日、年間標準、期間計画、期間実施、期間中止、年度実施、年度達成率を出力。期間計画は中止除外、実施は `done` かつ基準日・今日以前。年間標準は期間に比例配分しない。追加教科の標準は空欄。専科は担当教科だけ。メモや児童情報は出力しない。

UTF-8 BOM・CRLF・CSV引用符エスケープを使用。文字列セルの数式開始文字はシングルクォートで無害化し、Excelの数式実行を防ぐ。計算値は数値のまま出力。
